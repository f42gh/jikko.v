# Jikko 師匠マニュアル — by Claude

このディレクトリは、このリポジトリのコードベースを教材として、
**本当に実現したかった Jikko を自分の手で育てるための取扱説明書**です。

---

## このマニュアルの立場

「正解を教える本」ではありません。

あなたがいずれ**設計者として判断を下せる**ようになるための、
師匠との対話の記録として書かれています。

だから各章は、こういう構成になっています。

- **なぜそう設計するのか**（哲学・気持ち）
- **実際のコードはどう書いてあるか**（具体・事実）
- **どこが強く、どこが過渡期か**（現在地）
- **自分で書くときはどうするか**（実践）
- **ありがちな罠と解毒剤**（守り）
- **章末の鍛錬課題**（育て）

## このマニュアルが大事にしていること

### コードより判断基準を継承する

この repo のコードをそのまま模写しても、Jikko にはなりません。

大事なのは、**このコードがなぜこう書いてあるのか**という判断基準です。

判断基準が分かれば、コードは自分で書き直せます。

### 守破離の順序を守る

```
守 → 既存の設計思想の不変条件を体に入れる
破 → 弱い部分を見極めて、根拠を持って壊す
離 → 自分の言葉で判断を下せる
```

最初に「破」から入ってはいけません。
何を守るかが曖昧なまま壊すと、ただの解体になります。

### 小さく書いて、大きく理解する

最初から綺麗な設計を目指さないでください。

小さく書いてみて、それが何を守っているか・何を犠牲にしているかを
自分の言葉で言えるようになることが先です。
